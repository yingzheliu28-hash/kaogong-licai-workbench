## 二、新电脑上 5 步走

### 第 1 步：重建 GitHub PAT

在 WorkBuddy 里创建一个文本文件：

- **路径**：`C:\Users\LYZ\.workbuddy\secrets\wb_github_pat`
- **内容**：你的 GitHub Personal Access Token（需要 `contents:write` + `workflow` 权限）

没有 PAT 就去 https://github.com/settings/tokens → Generate new token (classic) → 勾选 `repo`（或 `public_repo` + `workflow`）。

### 第 2 步：装 Python

对 WorkBuddy 说：

> 帮我安装 Python 3.13.12

它会自动装到 `~/.workbuddy/binaries/python/versions/3.13.12/`。

> ```
> （粘贴对应提示词）
> ```

## 四、遇到问题？

| 现象 | 检查 |
|---|---|
| Python not found | 对 WorkBuddy 说「帮我安装 Python 3.13.12」 |
| wb_deploy_api 401 | PAT 文件路径/内容对吗？有 contents:write 权限吗？ |
| 站点内容没更新 | 跑一遍「第 4 步」三条命令 |
| 自动化没触发 | 时间到了没？电脑醒着吗？ |
| 错题知识点「去完整推送」没出现 | 小测题源模块标注格式对不对（必须 `法律·行政处罚种类` 不是单独 `法律`） |

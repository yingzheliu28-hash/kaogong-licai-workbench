## 二、新电脑上 5 步走

### 第 1 步：重建 GitHub PAT —— ⚠️ 有两处，必须都换

PAT 在本项目里有**两份互不相干的副本**，换电脑 / PAT 过期时**两处必须一起换**，
只换一处会让另一处静默失效。

#### 1-A. 本地副本（Python 推送脚本用）

在 WorkBuddy 里创建一个文本文件：

- **路径**：`C:\Users\LYZ\.workbuddy\secrets\wb_github_pat`
- **内容**：你的 GitHub Personal Access Token

没有 PAT 就去 https://github.com/settings/tokens → Generate new token (classic)
→ 勾选 **`repo`** 即可（`workflow` 可选，非必需）。

#### 1-B. Vercel 副本（站点「提交成绩」用）

1. 打开 vercel.com → 项目 **`kaogong-exam-api`**
2. Settings → **Environment Variables**
3. 更新 **`GITHUB_PAT`** = 与 1-A 完全相同的内容
   （顺带确认 `AUTH_KEY` = `wb-exam-2026`，与 `01_站点前端/app.js` 里的一致）
4. **点 Redeploy** —— Vercel 不热加载环境变量，**不重新部署改了也不生效**
5. 如果 `06_云函数/` 目录有改动（比如新增了 `api/health.js`），一并重新部署

> **为什么不能只换 1-A**：副本 2 失效时，本地脚本、站点浏览、每日推送**全都正常**，
> 只有「在线做小测 → 点提交成绩」报 HTTP 401，极难定位。详见 `README.md §2.1`。

#### 1-C. 体检确认

```bash
python 03_部署脚本/wb_check_credentials.py
```

看到「两份 PAT 副本均有效」= OK。若副本 2 显示「状态未知」，说明 Vercel 上还没部署
`api/health.js`，把 `06_云函数/` 重新部署一次即可变成可验证。

## 四、遇到问题？

| 现象 | 检查 |
|---|---|
| Python not found | 对 WorkBuddy 说「帮我安装 Python 3.13.12」 |
| 推送脚本报 401 | PAT **副本 1**（本地文件）过期 → 见第 1 步 1-A |
| **站点点「提交成绩」报 401** | PAT **副本 2**（Vercel `GITHUB_PAT`）过期 → 见第 1 步 1-B，**改完要 Redeploy** |
| 不确定哪份 PAT 失效 | 跑 `python 03_部署脚本/wb_check_credentials.py` |
| 站点内容没更新 | 跑一遍「第 4 步」的命令 |
| 自动化没触发 | 时间到了没？电脑醒着吗？ |
| 错题知识点「去完整推送」没出现 | 小测题源模块标注格式对不对（必须 `法律·行政处罚种类` 不是单独 `法律`） |

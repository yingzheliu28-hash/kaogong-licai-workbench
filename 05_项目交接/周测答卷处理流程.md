# 周测答卷处理流程（考公）

> 用户做完周六的小测后，**主动**对我说"小测做完了"，并附答案 + 错题笔记（可选）。
> 此文档是 agent 端的标准化处理协议，固定在 `05_项目交接/` 以便后续 agent 接手沿用。

---

## 触发方式

用户消息模板（任一种都生效）：

```
小测做完了，答案如下：
1-A 2-D 3-B 4-A 5-C 6-D 7-B 8-A 9-C 10-B
（错题笔记：第 3 题是阿拉伯数字陷阱；第 7 题是降级属于能力罚搞混了）
```

或者只贴答案，或者"做了 X / Y 题，对了 / 错了 Z 题"，都能处理。

---

## 处理协议（agent 必须严格按顺序执行）

### Step 1：定位题源

读 `公考常识判断/每周小测/<最近一个本周小测.md>`，解析每题：
- 题号
- 模块（①政治 ②法律 ③经济 ④人文历史 ⑤科技与生活 ⑥地理国情 ⑦管理公文）
- 你的选项、正确选项
- 错因（用户可选填；不填则 agent 从知识点推断，如"基本 vs 根本 层级混"）

### Step 2：写 `每周小测/<日期>-成绩.md`

**命名规则**：`<做题当天日期>-成绩.md`（与题源 `<小测日日期>-本周小测.md` 区分）。

格式参照 `2026-08-01-成绩.md` 现有样式：

```markdown
# 第 N 周 逐题成绩存档

> 周六日期：YYYY-MM-DD ｜ 小测作答日：YYYY-MM-DD ｜ 题源：YYYY-MM-DD~YYYY-MM-DD
> 得分：**X / Y**（N 题全对 / M 题错 K 题）｜ 薄弱模块：<总结>

| 题号 | 模块 | 你的选项 | 正确选项 | 结果 | 错因 |
|---|---|---|---|---|---|
| 1 | 政治·会议 | B | B | ✅ | — |
| 2 | ... | D | B | ❌ | 错把"基本政治制度"误当成"根本政治制度"，层级混淆 |
| ... | ... | ... | ... | ... | ... |
```

### Step 3：更新 `我的错题本.md`

读取现有 `我的错题本.md`，定位：
- 「错题重考池」——把本次新错题 append 进去（题号前用 `W2-3` 这种格式标记周次+题号）
- 「附：各周存档索引」——追加一行本次成绩链接

格式严格沿用既有 8/1 那份的入册形式：
```
- W2-3 · 法律·诉讼时效／你的选项 B／正确 D／法律／W2／未注意"约定无效"语义
```

## 硬性约束

1. **不写错题笔记时**：错因列填 `未填` 或留空，不要凭空捏造原因污染数据。
2. **部分作答（如只答了 8/10）**：未作答的题目记为空 / 视为错；并在成绩文件注明"未完成 N 题"。
3. **跨周日重测**：把跨周错题写入本周的"错题重考池"时，使用 `W<n>-<题号>` 编号保留溯源。
4. **永远只增不删**：`我的错题本.md` 的错题池**只追加不删除**——一题错即永久入池，直到用户主动撤销；每通过一次重考可在该题后标注 `✓W4` 但不删行。
5. **推送失败不阻塞**：网络/PAT 失败时本地文件已写，重试 1 次，仍失败就告诉用户手动跑 wb_deploy_api.py。
